# Редактор расписания

Локальное веб-приложение для просмотра и редактирования расписания учебных групп в Kundoluk. Приложение также позволяет публиковать расписание и формировать отчеты Excel.

## Возможности

- Просмотр опубликованного расписания и редактирование занятий.
- Выбор группы и смены, копирование занятий и применение шаблонов.
- Публикация расписания для выбранной группы или сразу для всех групп.
- Настройка соответствия групп и формирование отчетов Excel.

## Требования

- Python 3.
- Доступ к Kundoluk и действующий токен.
- Файл `report_template.xlsx` в корне проекта для формирования отчетов.

Зависимости приложения перечислены в `requirements.txt`.

## Установка и запуск в Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python server.py
```

Затем откройте в браузере <http://localhost:5000>. Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

Если команда `py` недоступна, используйте `python` вместо `py` при создании виртуального окружения.

## Первый запуск

1. Откройте приложение и вставьте токен Kundoluk в поле на экране.
2. Выберите группу и смену для просмотра или редактирования расписания.
3. Для публикации выберите неделю и подтвердите действие.
4. Для отчетов откройте раздел «Отчёты», настройте группы, учебный год и параметры, затем сформируйте нужные файлы.

## Локальные данные и безопасность

Токен сохраняется в `token.txt` в корне проекта. Не передавайте этот файл и не добавляйте его в Git. Настройки групп, шаблонов и отчетов сохраняются в `group_settings.json`, `templates.json` и `reports_settings.json`. Созданные отчеты помещаются в `reports_output/`.

Эти локальные файлы исключены в `.gitignore`. `report_template.xlsx`, напротив, нужен приложению и должен находиться в корне проекта.
